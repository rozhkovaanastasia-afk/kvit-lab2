# Kvit - лабораторна робота №2

Базова структура вебсайту для обліку спільних витрат. Використано HTML та SVG-зображення.

## Виконавиці

Рожкова Анастасія, Максимова Олександра, Медведєва Карина. Група КІ-43.

## Структура

- `index.html` - головна сторінка.
- `about.html` - опис сервісу та його аудиторії.
- `groups.html` - приклад групи та її витрат.
- `add-expense.html` - HTML-форма витрати.
- `contacts.html` - інформація про команду.
