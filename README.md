# Kvit - лабораторна робота №2

Базова структура вебсайту для обліку спільних витрат, створена за концепцією лабораторної роботи №1. Використано лише HTML та SVG-зображення.

## Виконавиці

Рожкова Анастасія, Максимова Олександра, Медведєва Карина. Група КІ-43.

## Структура

- `index.html` - головна сторінка.
- `about.html` - опис сервісу та його аудиторії.
- `groups.html` - приклад групи та її витрат.
- `add-expense.html` - HTML-форма витрати.
- `contacts.html` - інформація про команду.
- `images/` - компактне SVG-зображення.
- `css/`, `js/` - папки, передбачені завданням; стилів і сценаріїв немає.
- `docs/REPORT.md` - короткий опис виконаної роботи.

Файли `.gitkeep` потрібні лише для збереження порожніх папок `css` та `js` у Git.

## Запуск

Розпакуйте весь архів і відкрийте `index.html` у браузері. Переходи працюють через меню на кожній сторінці. Встановлення програм, Python чи запуск сервера не потрібні.

Форма використовує стандартну перевірку HTML. Після коректного заповнення відкриває ту саму сторінку з параметрами в адресі. Серверної обробки й збереження даних немає.

## Здача

Завантажте вміст папки `kvit` до віддаленого Git-репозиторію. До звіту додайте його фактичне посилання та скриншоти перевірки п’яти HTML-файлів у W3C Validator.
